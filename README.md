#MCP Library Management:

##MCP Lbrary Management is a python project-based that manages book records using SQLite and the Model Context Protocol(MCP). It provide tools to add, search, borrow books and also it includes resources to view the catalogue and also it has MCP prompt to generate book recommendation instructions.

##Features:
###1.Add book
###2.Search book
###3.Borrow book
###4.Book catalogue
###5.Book recommendation

##Technologies:
###Python
###Model Context Protocol(MCP)
###SQLite
###MCP Inspector
###Python Virtual Environment(venv)
